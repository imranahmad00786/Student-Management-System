# 🎓 Student Management System

A C++ based Student Management System designed to manage student records using file handling.

## 🚀 Features

- ➕ Add Student
- 🔍 Search Student
- 📋 Display Students
- ✏️ Update Student
- 🗑️ Delete Student
- 💾 Save Student Data to File
- 📂 Load Student Data from File

## 🛠️ Technologies Used

- C++
- Structures
- Functions
- Arrays
- Loops
- Conditional Statements
- File Handling
- `fstream`
